# Portfolio Website

My personal portfolio showcasing my background, skills, projects, and contact information.

## Live Website

Visit the deployed portfolio: **[portfolio-website-murex-beta-82.vercel.app](https://portfolio-website-murex-beta-82.vercel.app/)**

## Tech Stack

- React + Vite for the frontend
- Node.js + Express for the backend API
- MongoDB for data storage
- Vercel for frontend deployment
- Render for backend deployment

## Run Locally

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
node server.js
```

Configure the required environment variables for the backend and frontend before running locally. Do not commit secrets or credentials to the repository.
